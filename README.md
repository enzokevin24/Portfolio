# Portfolio Personal — Enzo Eduardo Camaño

Portfolio web estático (Versión 0.1) desarrollado para la materia **Aplicaciones Informáticas II (6º E)** del **Instituto Privado Mixto San Agustín** (Córdoba Capital, Argentina).

## Objetivo del Proyecto

Presentar de manera clara, ordenada y profesional el perfil de **Enzo Eduardo Camaño**, integrando su formación escolar en informática y robótica, su experiencia como auxiliar en taller mecánico y su capacitación práctica en barbería.

## Estructura del Repositorio

```text
├── index.html                  # Página principal del portfolio (HTML5 semántico)
├── README.md                   # Descripción general del proyecto
├── bitacora_ia.md              # Registro obligatorio de consultas con IA
├── css/
│   └── estilos.css             # Sistema de diseño rojo/blanco con degradados y animaciones
├── js/
│   └── script.js               # Animaciones por scroll, filtros, modal y menú móvil
├── assets/
│   └── img/                    # Foto de perfil e ilustraciones SVG sin dependencias
│       ├── enzo-perfil.jpg
│       ├── proyecto-edueventos.svg
│       ├── proyecto-robotica.svg
│       └── proyecto-barberia.svg
└── docs/                       # Documentación completa en Markdown (.md) y HTML (.html)
    ├── index.html              # Presentación web interactiva de la documentación
    ├── documentacion.md        # Explicación técnica del código y decisiones de diseño
    ├── guia-github-pages.md    # Paso a paso para publicar en GitHub Pages
    └── bitacora-ia.md          # Guía de autoría y defensa oral para clase
```

## Proyectos Destacados

1. **EduEventos — Organizador de Eventos Escolares:** Aplicación de escritorio en Python y Tkinter desarrollada en equipo para centralizar fechas, horarios y espacios de eventos del colegio.
2. **Autito Seguidor de Línea:** Proyecto de robótica educativa con sensores infrarrojos (IR), motores DC y calibración sobre pista.
3. **Formación en Barbería y Organización de Turnos:** Capacitación práctica enfocada en precisión manual, higiene de herramientas y gestión ordenada de horarios de atención.

## Publicación en GitHub Pages

El proyecto utiliza exclusivamente archivos estáticos (`HTML`, `CSS`, `JavaScript` e imágenes `SVG`), por lo que es 100 % compatible con **GitHub Pages** desde la rama `main` en `/(root)`. Consultá la guía detallada en [`docs/guia-github-pages.md`](docs/guia-github-pages.md) o abrí [`docs/index.html`](docs/index.html) en tu navegador.
